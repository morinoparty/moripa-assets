## 元画像の配置

元画像はリポジトリ直下の `assets/` に置きます。WebP・AVIF・JPEG やサイズ違いのファイルはビルド時に生成するため、リポジトリには元画像だけを置きます。

```text
assets/<category>/<group>/<name>.<ext>
```

| 部分 | 規則 |
|------|------|
| `<category>` | 素材の種類 (`logo`, `city`, `favicon`)。新しい種類を増やす場合はメンテナに相談してください |
| `<group>` | 素材のまとまり。小文字の英数字とハイフン (kebab-case) |
| `<name>` | `<group>` または `<group>-<variant>` (例: `morimoto-text`, `morinoparty-border`) |
| `<ext>` | `svg`, `png`, `jpg`, `jpeg`, `webp` |

- 同じ `<name>` の元画像は 1 つだけにします (`morinoparty.svg` と `morinoparty.png` を両方置くことはできません)。
- 元画像は、できるだけ大きいサイズのものを置きます。PNG はそのまま配信されます。
- ICC プロファイルは配信時に除去され、sRGB に変換されます。Display P3 などの画像は、事前に sRGB に変換したものを置くと確実です。
- 規則に合わないファイルがあると、ビルド (`pnpm assets`) がエラーになります。

## 生成されるファイル

`docs/` で `pnpm assets` を実行すると、`docs/public/` に配信するファイルと `manifest.json` が生成されます。
生成される形式は [使い方](/usage#形式) を参照してください。`pnpm dev` と `pnpm build` でも最初に実行されます。

## 街の素材

街の素材は `assets/city/<id>/` に、次の 2 つの元画像を置きます。`<id>` はローマ字の小文字です。

| ファイル | 内容 |
|----------|------|
| `<id>.png` | 風景画像 (1920x1080) |
| `<id>-text.png` | キャッチコピー＋街名の文字画像 (透過、高さ 220px) |

街を追加した場合は、[Introduction](/) とリポジトリの `README.md` の「街」の表も更新してください。

## 素材の変更・削除

素材の URL は他のサイトから参照されています。既存の素材を差し替える・名前を変える・削除する前に、参照しているサイトがないか確認してください。
