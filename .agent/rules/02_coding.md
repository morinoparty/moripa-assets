# 作業プラクティス

このリポジトリにはコードもビルドもありません。作業の中心は素材ファイルの追加・差し替えと `README.md` の更新です。

## 作業手順

1. **配置と命名を決める**
   - 既存の構成（`logo/`, `city/<id>/`）と命名規則に合わせて配置先とファイル名を決める

2. **素材を追加・差し替える**
   - 小さく始めて、関係のないファイルには触れない

## プラクティス

- 常に既存の構成・命名・形式を参考にしてください。
- 既存の素材は上書き・削除する前にユーザーに確認してください（他のサイトから URL で参照されている可能性があります）。
- ファイル名を変更すると参照先が壊れるため、リネームは避けてください。
- 素材を追加・変更したら、`README.md` の「構成」「街」の表も合わせて更新してください。

## 素材の規則

- 街の素材は `city/<id>/` に、1 つの街につき以下の 6 ファイルを揃えてください。
  - `<id>.png`, `<id>.webp`, `<id>.avif`（風景画像、1920x1080）
  - `<id>-text.png`, `<id>-text.webp`, `<id>-text.avif`（キャッチコピー＋街名の文字画像、背景は透過）
- `<id>` は README の「街」の表にある ID（ローマ字の小文字）を使ってください。
- PNG を元画像とし、AVIF と文字画像の WebP は PNG から sharp で生成してください。
- `logo/` は morino.party の `/assets/` 以下と同じ構成を保ってください。

## 作業後の確認

ビルドの代わりに、作業後は以下を確認してください。

- `git status` で、意図したファイルだけが追加・変更されていること
- 街の素材が 6 ファイル揃っていること（何も出力されなければ OK）:

```bash
for d in city/*/; do id=$(basename "$d"); for f in "$id" "$id-text"; do for e in png webp avif; do [ -f "$d$f.$e" ] || echo "missing: $d$f.$e"; done; done; done
```

- `file logo/* city/*/*` で、拡張子と実際の形式が一致していること（風景画像が 1920x1080、文字画像の PNG が RGBA であること）
- `README.md` の表が実際のファイル構成と一致していること
