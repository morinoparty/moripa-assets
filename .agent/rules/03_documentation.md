# ドキュメント

## ドキュメントの作成

- このリポジトリのドキュメントは、ルートの `README.md` と、ドキュメントサイト（`docs/content/docs/`、https://assets.morinoparty.workers.dev/）です。
- 素材の一覧ページ（`docs/content/docs/gallery/`）は `manifest.json` から自動で表示されます。新しいカテゴリを追加した場合は、一覧ページと `meta.json` を追加してください。
- 素材を追加・変更・削除した後は、`README.md` の「素材」「街」の表や「出典」と、ドキュメントの該当ページを更新してください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも文章の文体で記載してください。
