# 推奨される書き方

## 画像形式
- 元画像は PNG（ロゴなどは SVG）で保存することが推奨されます。WebP・AVIF・JPEG はビルド時に生成されます。
- 元画像は sRGB で保存することが推奨されます（Display P3 などの ICC プロファイルは配信時に sRGB に変換されます）。
- 背景が必要ない画像（文字画像など）は透過 PNG にすることが推奨されます。
- ロゴなど拡大縮小して使うものは、可能であれば SVG を使うことが推奨されます。

## 出典
- 他のリポジトリやサイトからコピーした素材は、`README.md` の「出典」にコピー元と確認日を記載することが推奨されます。
- 画像の加工・変換は元画像から行い、配信用に生成した画像（WebP / AVIF など）から再変換しないことが推奨されます。
